# CONTEXT.md — shared vocabulary

Domain and architecture terms used across Entieve. Domain canon lives in
`docs/lore/` (UNIVERSE, FACTIONS, AESTHETIC, NAMING — binding); this file
names the *modules and seams* we build that vocabulary into.

## Domain (the world)

| Term | Meaning |
|---|---|
| **Corporation** | a named manufacturing house (`corp-*`, `content.AllCorps`): the maker of a hull, module or charge, carrying a display name and an emblem; a supplier layer, never a power bloc |
| **Hull** | a ship chassis (`ship-*`); flyable or machine |
| **Hull portrait** | top-down full-colour art of a hull for the HUD/Show Info (`uikit/hulls`): a flat SVG source in `svg/` rasterized at build time to committed 120/240 px PNGs, keyed by hull id (`Get`/`Has`) |
| **Module** | a fitted component (`mod-*`); slot-classed high/mid/low |
| **Mount** | a hull's high slot, declared as a kind and a size (`high_mounts`); a mounted module needs a mount of its own kind at or above its size, so a large gun never sits on a frigate |
| **Turret mount / launcher mount** | the two mount kinds: guns and the mining laser are turret-mounted, rockets and missiles launcher-mounted |
| **Grid class / cpu class** | a module's powergrid or cpu demand as one of three classes — Class I / Class II / Class III — never a number; a module demanding both axes consumes one unit on each |
| **Class quota** | a hull's per-class allowance on each axis (`grid_classes` / `cpu_classes`); a fit is legal while no class's module count exceeds its quota, which is what bounds a full rack |
| **Item** | everything else tradeable: ore, mineral, charge, round, loot (`ore-*`/`min-*`/`ammo-*`/`charge-*`/`loot-*`) |
| **Tradeable** | any marketable id — item, module or hull — resolved through one ladder (`widgets.ResolveTradeable`, item → module → hull, the sim's `itemName` order): kind, display name and themed icon (drop-in art wins), or the raw id with no icon and no ref when no def backs it |
| **Round family** | a round size class **and** gun family as one `ammo_class`: `small-autocannon`, `small-artillery`, `medium-autocannon`, `medium-artillery`, `large-autocannon`, `large-artillery`. One family is one calibre: every round of it has the same m³ volume, and only guns of that family load it (autocannon = rounds, artillery = shells) |
| **Round** | the ammunition item (`ammo-*`) a projectile gun loads: its family + one of the four damage profiles; the gun's `damage_multiplier` is its share of the round's volley (autocannon light and fast, artillery heavy and slow) |
| **Bay** (clip) | a charge-consuming module's fixed m³ ammunition space (`weapon.bay_m3`, `boost.bay_m3` for the cap booster): whole rounds of exactly one round type, sized so sustained fire reloads about every 120 s |
| **Load cycle** | filling a bay from cargo: a full bay's rounds, taking exactly one firing cycle (no capacitor cost), so the next shot is deferred by it. The rounds move in at the start; the bay is ready when the cycle completes (the rack draws the ring lit meanwhile and a shell marker once armed). Also what `CmdSetAmmo` starts when it switches a round type; only the fresh fit at boot is pre-loaded instantly |
| **Waiting state** | a bay sitting empty while two or more round types compete in cargo and none is selected: the gun logs one `<module> waiting for ammo selection` line, deactivates quietly, and fires only once `CmdSetAmmo` picks a type. Distinct from truly dry (empty bay, no matching cargo rounds = the `no charges` warning) |
| **Caste** | an Old Works machine archetype (`npc-*`: Scuttler, Marauder, Hierarch) + the Charter patrol (Kuštor) |
| **Station** | a market/service node (a celestial); stations hold the order books |
| **Service** | a station's offered capability, owned by one table (`content.Services`): the id content files spell, its display label and icon, and the Screen window its services-row button toggles (`repair` opens none) |
| **Order book** | per-station continuous double auction: asks + bids, never-crossed |
| **Market tree** | the market window's browse hierarchy, built from every marketable def's `group` path (`Ships/Frigates`, `Modules/High/Turrets`, `Materials/Ore`, …): `All` at the root, a branch click scopes the catalog, and the search field filters the selected branch by name, path and maker |
| **Bid** | a standing *buy* order on a station book: buy at your price or better, resting until filled or cancelled |
| **Ask** | a standing *sell* order on a station book: sell at your price or better, resting until filled or cancelled |
| **Open order** | a player's standing bid or ask resting on a book — up to 20 universe-wide, partial fills accumulate, cancelled by id (3% broker fee charged at placement and kept on cancel; 2.5% sales tax on executed sells) |
| **Recipe** | two-tier manufacturing: minerals → products (`rec-*`) |
| **Job** | one manufacturing run queue at any station (industry); all stations share three global job slots |
| **Manufacturing** | the industry window (key B): recipe board with per-run time, up-front fee and one run's inputs, the three global slots, and the **quantity picker** on a recipe selection (runs 1–100) whose Confirm starts the job; the job list keeps Collect/Cancel. Renamed from Factory; its layout sidecar key is `manufacturing` (old `factory` files migrate on read) |
| **Job fee** | 3% of a recipe's mineral value at base prices, per run, debited from the wallet at job start; kept on cancel |
| **Refinery** | the ore→mineral window at a `refine` station: ore list from cargo + ore hold, each stack's one-batch `floor(refine_yield × qty)` yield, and the **quantity picker** on selection (its notched ladder offers 100/200/300…, capped at the selected ore's stock; under 100 ore nothing refines). The minerals always land in the station hangar, never the ship's hold |
| **Craft level** | a station's learned skill per product family (grows with volume) |
| **Belief** | an agent's EWMA of executed trade prices (its market view) |
| **Haul wish** | an agent's cross-node arbitrage intent, flown as a real convoy |
| **Warp process** | align → accel → cruise → decel; spatial easing over a frozen timeline |
| **Departure beat** | the jittered 2–8 s hold a convoy keeps after spawning, resuming or arriving before it commences its warp — a stateless tick hash, never a persisted timer |
| **Gate cycle** | a stargate transit in two paced parts: the *dwell* (2–5 s at the gate before the hop) and the *jump cycle* (1–3 s between hop-out and materializing at the destination gate) |
| **Turnaround** | a station visit in stages: approach (2–4 s) → docked dwell (5–15 s, the cargo/market action fires partway through) → undock + departure beat |
| **Hold** | a shipment parked upstream of a full gate queue: it waits in the journey ledger until the far queue drains, logging one line on entering the hold and one when it finally jumps |
| **Agent cooldown** | per-agent jittered 1–10 s between behavior acts; one act moves capital at most once (its job / quotes / wish slot rotates on a stateless tick hash) |
| **Belt sweep** | the security response to pirate rats parked on a Charter-space (high-sec) belt: a static guard clears the rats anchored at its own celestial, and a traffic patrol sweeps an occupied belt once per **patrol beat** (the authored patrol cadence, re-armed after every sweep) and flies home. A sweep stays until the belt is empty and hunts stragglers off the anchor; free rats are engaged first, and a fight a pilot is already in is theirs only while another rat is free. The Fringe / Unincorporated get no sweep. The last rat of a belt dying logs one `<belt> cleared` line; the belt's respawn timers re-arm it. Every high-sec station carries a four-cutter static post (Rydnok's belt too; the Struvok belt is the one authored exception — no post, held by the station's cutters, the response wing and the sweep), and a high-sec patrol schedule comes round every minute |
| **Hostility** | who may initiate on whom: [lore/FACTIONS.md](docs/lore/FACTIONS.md)'s Relations table as code (`sim/hostility.go`, faction string → the factions it may act against). Only the Old Works are hostile (everything non-Old-Works: traffic, miners, you) and the Charter answers them; corporate houses, independents and unknown factions initiate nothing (fail closed), and same-faction pairs are never hostile. Role passivity stacks on top: guards never initiate (self-defense and the high-sec belt rule aside), miners never initiate — they do flee when damage takes their structure under the temperament threshold. High-sec security is overwhelming: the Kuštor carries three medium autocannons and ~2000 EHP, a response wing is ten cutters, and a high-sec post leaves no belt unguarded. Security also answers miner distress: a Dvužek barge hit in charter space draws the same wing, held on the barge and the rats around it (one live response per miner, none inside Works control — see **patrol response**). The threat machine (`sim/systemNpc`) is a **behaviour tree** over the player, AI hulls and traffic haulers alike — one candidate-based rule set, so a mining op that draws a rat draws it the same way your lasers do (shipped content with a faction and no relations row fails a test); among the candidates it triggers, **prey preference** ranks the engagement and a **threat switch** re-targets a fight already under way |
| **Behaviour tree** | how an NPC role decides one tick: one tree of named rule leaves (`sim/btree.go`, `sim/system_npc.go` — `aggressiveTree`, `guardTree`, `minerTree`, `patrolTree`, `raiderTree`) evaluated by `Sequence`/`Selector` in declaration order. Stateless: no clock, no goroutine, no RNG, no per-tick allocation; a leaf reads world state and writes the decision, and `NpcAI.State`/`Target` plus the tick's `Intent` are the only memory — so the tree is re-evaluated from scratch every tick and survives save/restore through the NPC state it produces. Motion (patrol circles, approach/orbit, flee, warp) stays in the routines the leaves call; traffic leg scheduling and war episode timelines are not trees |
| **Prey preference** | which triggered candidate an aggressive NPC engages: the damage source first (initial aggro), else the highest prey score `0.5·(carry/max carry) + 0.5·(guns/max guns)` over the eligible set — carry = cargo capacity + ore hold, guns = fitted weapon modules, maxima set-relative, equal weights; equal scores go to the nearer candidate, then canonical handle order. Guards rank the rats they clear the same way; raiders and patrols keep the incident's assignment |
| **Threat switch** | when an engaged NPC changes target: another hostile's damage over the trailing 120 ticks must be ≥ 2× the current target's over the same window (`npcSwitchLead`) and 600 ticks must have passed since the last acquisition or switch (`npcSwitchDwell`); the window then restarts and the hull re-enters approach. A wing-mate of the current target never triggers it, a hull with no live target still answers any attacker immediately, and the same rule gates the engaged-idle guard/raider flip. The damage window and dwell marker are transient (`NpcAI.HitLog`/`SwitchAt`: not saved, so a restore starts the window empty, like the player-work marker) |
| **Patrol response** | the Charter's answer to an incident, dispatched by `trafficRespond` with a `trafficPatrolWing(σ)` wing (ten high, one low, none null) at a convoy ambush or — the second incident kind — a miner under fire (`minerDistress`: any hostile hit, one live wing per miner, never inside Works control, delayed in low space by holding the wing at the anchor). `patrolMinerStep` holds station on the barge and clears the rats within the ambush engagement range of it; responders never initiate on the player |
| **The Long Attrition** | the war of the Wild Fields: corporate fleets under the Commission fight the Old Works for territory; charter ⇄ unchartered flips are its scoreboard, the contest meters its pulse, and the economy feeds it. Rare flips, always on, from tick 0 |
| **War** | the sim's war state (`sim.WarState`, one additive `Save` field): per-system **control** (`charter`/`works`, seeded from the authored security tier — `high`/`low` → charter, `null` → works), the front's **contest** meters, and the **war treasury**; ticks with the sim, never wall-clock |
| **Effective security** | what a flip leaves behind: control-derived security that re-derives every behavior the authored tier used to drive (guards, patrols, temperament, ambush rates, sweeps). Fall → `null`; reclaim → the authored tier returns |
| **Front** | the contiguous boundary where charter and works control meet across gates; every system on it carries a contest meter, and the war moves only here |
| **Contest** | a front system's charter-vs-works meter: pushed by **supply** (procurement credited to it, plus kill attrition) and eroded by **works pressure** scaled by the squeeze curve; crossing the threshold flips the system — rare by construction |
| **Squeeze curve** | the Works' exponential resistance as their territory shrinks: one global curve off works share, acting on the meter pushback AND the grid (spawn mix shifts toward tougher castes). The Works can be cornered but never extinguished — the war never ends |
| **Procurement** | the war's standing demand: treasury-funded bids on every charter-held book for everything military. Fills pay the seller at once (your earnings), consume the goods (the sink), and credit supply to the nearest front after an abstract haul delay; NPC haul convoys cart war goods toward the front wherever you are to see it |
| **War treasury** | the Corporate Fleets' ledger, seeded like a faction ledger and refilled by the **fee cut** — a share of broker fees and sales tax rerouted instead of burned. Its balance is war health; the war mints nothing, and starve the economy and the charter loses |
| **Remnant** | a station after its system falls: market and repair stay live (lawless), charter services (contracts, industry, fitting) go dark, guards leave, and the Works take the belts — never the docking ring. Reclaim restores the authored set |
| **Corporate Fleets** | the bloc faction behind the commissioned fleets: hostile to the Old Works only, neutral to everyone else unless provoked. One row now; per-corp rows may grow later when a corp needs its name on screen |
| **The Svaz** | the weak confederation binding the cantons and the corporations — heart in the old worlds, a dues line and a warrant at the rim: treaty, dues, the Commission. Institutional only: no office, no officer and no answer in the Wild Fields. "The empire" in prose |
| **The Commission** | the Svaz's war commission: the mandate under which corps raise and crew fleets. The Charter stays army-less — its law is insurance, not war |
| **Predecessors** | the civilisation before the settlement waves: it built the Old Works and lost the oversight, and why is not preserved. Known through oral tradition, a scholarly fringe and the machines themselves — never a witness, an archive or a name of its own |
| **the Kanžar Inspectorate** | the Svaz's ban on machine minds and autonomous self-replicating systems, in institutional form: a name on a form. Offstage by canon — no office, no officer, no hull, no sim state, never a screen |
| **Legacy id** | a content id a rename retired, mapped onto its replacement in `content.LegacyIDs` (the keys are `content.RetiredIDs`): validation rejects them in shipped content, and restore remaps them in place — `sim.walkContentIDs` finds every id a save carries by reflection, so a new id-bearing field needs no second list |

## Architecture (the UI tranche)

| Term | Meaning |
|---|---|
| **Screen** | a window the player can open: declared as one **Screen spec** row (id — the frozen layout-sidecar key —, title, icon, key, default rect, dock policy, build) whose built **Screen panel** the **Screen host** mounts, syncs, dismisses and places. The layout sidecar, the frame sync, the × close and the title-bar name all read the host (that name is the row's static display name — a title bar carries no live state); a transient row keeps its id but no sidecar entry |
| **Screen host** | the Game-free state machine between Screen rows and their panels (`game/screenhost.go`): one instance for the game table, one for the title's own table (a title host's rows follow their flags — its table IS the title set). It owns the open flag, the mount (spec order), the mount-frame Sync, the committed-close dismissal, the layout entry and the placement tracker; **Rebind** drops the panels with a rebuilt kit and keeps the open flags |
| **Screen panel** | a Screen row's built product: a `widgets.WindowPanel` (window + Sync). Optional capabilities are asked by type — `Splits()`/`Tables()` for layout persistence, `Dismissed()` for the committed × close, `Unmounted()` for teardown, `FitSize()` for a content-hugging window (the **Fitted** facet: the host mirrors the **Station board**'s floor onto MinSize and composes its declared column through the placement tracker) — so a window persists or hooks by implementing the facet, never by appearing in a name switch |
| **Station board** | the docked station's contract panel (`uikit/screens/stationboard.go`): the **Station services** row (docked-at identity, Undock, Cargo, this station's services) over the Available and Active contract **rich rows**, rebuilt from one comparable model and fitted to its content. One **ContentView** read feeds it (`Contracts{Station, Standing, Board, Active}`); Accept/Abandon are typed **intents**. The **Screen host** mounts it (the one window docking opens) and applies its `FitSize()` floor, so the window hugs the board and its **MinSize** is the content floor |
| **Keybindings** | the player's key overrides: a `{version, binds}` sidecar beside the save (`<save>.keys.json`) holding **only** the deviations from the defaults, action id → key (or `null` for an action left unbound). Rebindable actions are the **Screen** rows' toggles (their `Action` ids) and the world commands (the **World verb** action ids in `uikit/screens/worldverbs.go` — `lock-nearest`, `lock-selected`, `high-1`…`high-8`, `approach`, `orbit`, `stop`, `align`, `warp`, `dock`, `jump`, `loot`, `mine` — plus the held camera pan `pan-up`/`down`/`left`/`right`). The window is sectioned by where an action is declared — **Ship controls** (`worldKeyMap`), **Windows** (the Screen spec) and the dim, non-interactive **Fixed shortcuts** block (the chords below) — with one key chip per row. **Replace policy**: a key belongs to one action, so binding an occupied combination steals it from its holder (which becomes unbound, shown `—`); a row can also be unbound directly (`Backspace` while it waits) or reset to its default on its own, and replaying the overrides over the defaults on load reproduces the same state. The global chords are a fixed, never-rebindable layer — `Esc` (reserved even as a plain binding), `Ctrl+S`, `Ctrl+F`, `F9`, `[` `]` `-` `=` — handled literally before the data layer |
| **Key hint** | one action's key line wherever a surface prints it — the help overlay's rows, the rail tooltip, the keybindings chip, the settings footer — read live from the binding table (`game/keyhints.go`: `Chord` / `Desc` / `Hint`, the fixed chord layer answered from its own literals and never from `binds`), so a rebind shows on every surface with no rebuild or invalidation. The declaration tables hold the **description only** (`Screen.Desc`, `worldKeyMap`) and `keyMapRow` composes `game.KeyMap`'s "chord — description" rows with the one `chordOf` formatter; `screenSpecErrors` rejects a description carrying a chord (the rot guard). uikit consumes it through two seams — `RailEntry.Hint func() string` (the tooltip's line, and part of its change key so an open tip cannot keep a stale chord) and `SettingsActions.CloseHint func() string` ("" = the Close action is unbound, so the footer drops its clause). An unbound action shows `—` in a chip and `· unbound` in words; `""` means "no chord", never a dash |
| **Title screen** | the boot phase (`Options.StartInTitle`, set by the `run` command only and never with `--load`): the embedded `assets/artwork/title_background.jpg` draws cover-fit as the backdrop under the title menu (the already-built world's static render is the fallback when the plate is unavailable), the simulation does not step, and gameplay chrome (rail, HUD, rack, core windows, log) stays unmounted; leaving it runs one normal boot reconcile |
| **Title window** | one of the title screen's own windows, declared as a Screen row of the title's **one** table (`game/title.go` `titleRows`): the transient Save manager, the game table's `InTitle` rows (Settings, Keybindings) and the transient Credits, in mount order. The title's Screen host mounts them lazily and exclusively over the menu, and the menu rows, the live key bindings (`actionFor`, so a rebind moves a title window's key too) and every `×` drive the same open flags; an `Unlisted` row (Keybindings) keeps its slot but gets no menu label — its door is the Settings window's button. The two title-only rows are `DockTransient`, modal and unkeyed, and no title row ever enters the game table, the KeyMap, the layout sidecar or the rail |
| **Save manager** | the title screen's window over the saves directory (`filepath.Dir` of the configured save path): `*.json` save files only (layout/settings/keys sidecars excluded; an in-flight atomic-write temp `.<doc>.<random>.tmp` ends in `.tmp`, so it is never listed nor counted by **Save as…**), newest first, with **Load** and a two-click **Delete** |
| **Music** | the client's soundtrack: one shuffled pool over the six embedded tracks (`assets/audio/*.ogg`, embedded by the shim beside them), playing everywhere (title, space, station) and advancing when a track ends; master × music volume (100% × 70% fresh install, `master_volume`/`music_volume`, shuffle on) is applied at the `game.Music` seam. Tests get a silent nop — the real engine is constructed only on the `run` path, because the audio context may exist once per process |
| **UI sounds** | the five interaction cues (`click`, `open`, `close`, `confirm`, `refuse`) embedded from `assets/sfx/*.wav` and played by the `game.UISound` seam: master × UI applied at the seam (100% × 80% fresh install, `ui_volume`), nop in every test/headless path, the real players built only on the `run` path beside the music on the same one audio context. **Click** speaks only for a control — `Kit.PressTarget` walks the deepest widget under the press up its ancestors (button, text input, slider grab band, context-menu popup) and the host answers for table rows, whose scroll viewport hides them from the walk; window bodies, title bars, labels and dead space are silent. **Open/close** come from the Screen host's mount/unmount edges, silent for the boot composition and for a rebuild's remount (those windows were already open); **open** also speaks for the context menu appearing — `Game` reads the popup's closed→open edge at the frame's start (kit-level, so no mount edge covers it), and its dismissal stays silent (the press that closes it is the click cue's own gesture) |
| **Active save path** | where **Save** writes (Esc-menu Save / Ctrl+S): the configured save path until a load or a **Save as…** makes another file active; layout and settings sidecars stay keyed to the configured path |
| **Document store** | the one reader/writer for the JSON documents beside a save (`docstore`: layout, settings, keys, the save itself). **Load** is tolerant: a missing, corrupt or out-of-range file leaves the caller's defaults in place and reports `ErrMissing` / `ErrFormat` / `ErrVersion` — sidecars ignore the error, the save path reports it. **Save** is atomic: the exact `MarshalIndent` bytes into a dot-hidden `.<doc>.<random>.tmp` in the same directory, chmod 0644, fsync, rename, so an interrupted write never truncates the old document. Paths, version numbers, migrations and defaults stay in `game` |
| **DockPolicy** | where a Screen's window lives: `floating` (placed by `placeDefaults` from its declared rect — every window, the docked **Station board** included) or `transient` (scene-owned, never persisted — the Esc menu) |
| **Anchor** | which edges of the viewport a floating Screen hangs its design-unit default rect on: centred, a fixed design coordinate, bottom-left insets, or top-centred |
| **Row** | one listed entry in a table; its interactions derive from its **RowSpec** |
| **Market tree** | the market window's order book as one parent row per catalog item (every tradeable item, module and hull, always listed; dimmed while it has no orders, still fully actionable) with that item's resting orders folded out beneath it on a click — asks ascending, then bids descending — and the item row's own price (the station ladder) and two-side quantity. The fold state is session-only: never saved, forgotten when the window closes |
| **RowSpec** | the row's declared data: `Ref` (what it *is*, for Show Info) + `Actions` (typed intents it offers). One installer applies menu, tooltip and double-click uniformly |
| **Rich row** | a `TableRow` carrying a **line stack** (`Stack []RowLine`) instead of one text per column: runs of cells with their own step/colour/width, `Icons[0]` boxing with line 1, `Spec.Actions` drawn as trailing buttons (1–2, grayed-not-hidden) and a per-line `Ref` for the installer — the contract board's row form (`widgets.StackRow` builds one, `widgets.StackLayout` tiles a section of them) |
| **Plain table** | a decorless column list: aligned columns, no header, no row tints/zebra, no borders — dense label/value rows for readouts like the Finances holdings block. `widgets.PlainTable`: leading columns pack at their measured widths, the last column stretches to the row's right edge, so a value column's End anchor lands on one shared x in the mono tabular face |
| **Theme** | faces + scaled metrics + palette — the visual constants a widget draws itself with (the seam interface and its implementation live together in `uikit/theme`); a Theme-only widget takes it alone |
| **Spacing tokens** | the furniture rhythm in `uikit/theme` design units: `SpSm`/`SpMd`/`SpLg` = 4/8/16 (insets, button/title-bar padding, the scrollbar handle). Furniture takes its air from them; **data rows keep their own denser literals** (the table's `cellPad`/`entryPadV`) — table density is deliberate |
| **Scroll gutter** | `theme.ScrollGutter` (SpLg + 2×SpSm = 24) — the column reserved beside every scroll viewport for its scrollbar, so the handle can never overhang the content and the viewport never jumps between fit and overflow. Built once as `widgets.ScrollRail` (slider in the gutter, hides while the content fits); carried by `widgets.Table`, the station rail's entry column and the Show Info page |
| **Split pane** | `widgets.SplitPane`: panes divided by draggable **seams** instead of GridLayout's equal shares — a vertical stack (`NewSplitPane`) or a row (`NewSplitPaneRow`, the market's book / My orders). A seam is a recessed 4 px track (dark fill edged in the border color) with a centred three-dot sash grip — dim at rest, lit while hovered or dragging — and an 8 px grab band classified from the cursor every frame (the window chrome's grip idiom); the cursor is NS-resize in a stack, EW-resize in a row. Each pane keeps a 72 design-px floor so nothing collapses. Every seam is named for the layout sidecar (`inventory-ore`, `inventory-hangar`, `fitting-hangar`, `manufacturing-jobs`, `market-orders`) and stores **the fraction of the stack before it** — above in a stack, left of it in a row; equal shares when nothing is stored (the market opens at the book's 240/526 share, today's fixed side column) |
| **Slider** | `widgets.Slider`, the house draggable value control in two modes: **freeflow** (a continuous range quantised only by its own step — the settings window's Master/Music/UI volumes, whole percents) and **notched** (an explicit ascending ladder the handle snaps to and marks with one dim tick per rung — the UI-scale slider over the six rungs). One 40 px row, a 24 px grab band centred on a thin rounded track, accent-filled to the handle. A press anywhere on the band jumps the handle to the absolute cursor x (never a delta), the held pointer keeps it there, and release ends the grab; the input layer check makes a slider under another window inert. The host gets two callbacks: **OnChange** streams the live value while the drag moves (audio applies it, the UI-scale host rebuilds at a rung) and **OnRelease** fires exactly once per grab, the persist point (one sidecar write per drag, however many values it streamed) |
| **Quantity picker** | the one replacement for every −/+ ticker (`uikit/screens.QtyWin`, `Session.QtyWindow`): a small **modal**, transient popup — title, item line, one **Slider**, the picked value, a live preview, Confirm and Cancel — that asks for exactly one action's quantity and emits that action's existing intent. It is **hybrid-triggered**: the selection-driven windows open it on the item (refinery: an ore; manufacturing: a recipe), the multi-action windows open it per verb on the selected item (market: Buy/Sell; inventory: To Cargo/To Ore/To Hangar/Sell), and every row's right-click quantity action routes through the same picker. Slider model per surface: the refinery's **notched** whole-batch ladder, everything else **freeflow 1..100 step 1** (no new clamping — the sim still arbitrates stock, book and funds). One instance per session, mounted by the Kit on first open (`Kit.OpenQty`), seeded with the surface's last **confirmed** value (clamped to the live range; a rebuilt interface starts at 1); Esc cancels it before any window close, Confirm/Cancel close it, and a cancelled picker writes no intent and no memory |

| **Dialog** | one on-demand Kit window's lifecycle (`uikit/screens/kitdialog.go`, **Kit-internal**: unexported, no new public surface): its `win`, the panel's `hide`/`isOpen` closures, an optional `place` hook and the live mount handle. One `newDialog` registers the window's `×` (`SetWindowClose`); one `showDialog` absorbs the launch rules — re-target first (a refusal mounts nothing), then `place`, then remove + re-add on top with `animate = false` when already open, and a launch during a close fade drops the pending unmount and fades back in; `closeDialog` is idempotent (unmount, hide). Show Info, the order mini-window and the quantity picker are its three instances — only the picker sets `place` (it centres on every show; the other two never jump on a re-target). `addWindow`'s fade/settle/stack rules, `raise`, `Over` and the panels' own `Show`/`hide`/`IsOpen` stay out |
| **Column prefs** | a table's per-column state (`widgets.ColumnPref`): the width and hidden flag the player sets through the header's **grips** (6 design-px strip at each column's right edge, its own blocking input layer, EW cursor) and the **⋯ column menu** (flat, one ticked row per column, last visible column disabled). Two policies: the **first fit** measures the content once and freezes each column's base — later content changes ellipsize, never move an anchor; **every later layout** (table resize, hide/show, stored prefs) distributes the table width over the bases **proportionally**, so a player-made width persists, a hidden column restores its base and a grip drag or table resize re-bases at the widths on screen. Every table tags itself with a sidecar id (`widgets.PrefsID`); widths and hidden flags ride the layout sidecar's `tables` map in design units |
| **ContentView** | the read-only seam: defs + observable sim state as screens see it, implemented over `*content.Content` + `*sim.Sim` — screens never see the simulation |
| **ActionSink** | the write seam: screens emit typed **intents** (`Buy{Item,Qty}`, `StartJob{…}`, `QtyPick{…}`) through `Do(Intent)`; the game executes them (`Game.Do`); later the AI surface will emit the same ones |
| **World verb** | one row per in-space command (`uikit/screens/worldverbs.go`): `Action` (the frozen `worldKeyMap` id — the row's only name; a surface that speaks a verb carries its own wording, e.g. the Selected Item caption), `Rule` (`TargetSelected`, `TargetSelectedElseNearest`, `TargetNearest`, `TargetCycle`, `TargetSelf`), `Eligible` (may act at all — the key path, the panel and the nearest-fallback filter), `Ready` (the panel's disabled state and why text only; a sim refusal stays the key path's feedback) and a pure `Emit` that builds a `widgets.Intent` — never a command, `commandFor` stays the only intent→command table. The key path (`Game.worldKey`), the Selected Item buttons and the overview row actions all resolve through these rows, and the AI surface emits the same intents (the ActionSink promise). The Selected Item panel's buttons are one declared slice (`selectedPanel.verbs`): build appends a row per verb and `syncSelected` gates that same slice, so a button cannot exist without its gate |
| **Seams** | the union `Theme` + `ContentView` + `ActionSink` plus the host's **Pointer frame** — the constructor param of a screen that draws, reads *and* acts (`uikit/widgets.Seams`; the dissolved `Env` is only this alias) |
| **Pointer frame** | one frame's gesture (`uikit/widgets.Pointer`): ONE sample of the pointer per Update (`Begin`, the host's first line) — position, held buttons, press edges — that every widget reads instead of the OS, so the world and the interface hit-test the same point. `Press` is the frame's edge unless the frame **spent** it (`Spend`, the context menu's Click/Esc own the gesture), `RawPress` is the edge always (Menu.Poll's own read — the popup acts on the press that dismisses it), `Down` is the held state. It also owns the frame's **shape**: claimers only declare (`ClaimShape`, last claim wins — the chrome steps after the pane polls, so a grip outranks a seam) and `Apply` (the host's end of Draw) writes the winner once, never re-sampling, so ebiten's draw-only frames repeat the last decision instead of falling back to the arrow. Widgets keep what a gesture *means* (a seam grab, a column drag, a menu dismissal); the frame only says what the pointer *is*. One per host, owned by the `Game` (`Options.Pointer`, survives a kit rebuild), reached by every panel through `Seams.Pointer`; a `Source` supplies the sample (`OSInput` in production, a script in tests) |
| **Hit test** | one press-ownership walk (`uikit/screens/hittest.go`): `Kit.Own(pt)` answers where a point lands — `Owner{Layer, Window, Control}` over `World`, `Popup`, `TopChrome`, `Window`, `RootChrome`, `Hovered` — in exactly this precedence: the popup latch (`Kit.Held`, set by `MenuInput`/the picker's poll, Control sampled before the poll so the press that runs an entry still counts), the popup's own rect (`MenuRect`), a visible **modal** window (its input layer is fullscreen, so nothing below it is owned), the top chrome (the rail), the window stack topmost first (its widget walk, then the window's registered row surface — `SetWindowRows`, one live closure per mount, since a table's rows sit in a scroll viewport the walk cannot descend into), the root chrome's **descendants only** (the HUD container stretches over the whole screen and owns nothing by itself), and last ebitenui's hover flag, which gates but never raises. Every consumer reads it and nothing else: `Over` = layer ≠ World (the host's world gate), `PressTarget` = `Control` (the click cue), `raisePressed` = a press edge whose owner is a window that is not the stack top. `Popup.Control` is true for the popup's entries (and the picker's controls) only: a press that just dismisses the popup stays silent |
| **Session** | one host's environment: the three seams plus its pointer frame and its shared context menu, Show Info window and quantity picker (`uikit/screens.Session`, from `Kit.Env` / `NewEnv`) |
| **uikit modules** | `uikit/theme` (visual constants + the Theme seam) ← `uikit/widgets` (mechanics: table, menu, tooltip, rowspec, intents, seams) ← `uikit/screens` (the panels + Kit): each layer imports only downward, pinned by `TestImportDirection` |
| **Deep module** | a module whose interface is small and whose implementation absorbs complexity (the goal of every seam here) |
| **Close button** | the `×` affordance at a title bar's right edge: registered per window through `Kit.SetWindowClose`, wired to that window's existing close semantics (Screen-row toggle, core toggle, Show Info close). Its hit strip is excluded from the chrome-owned title drag; the window's resize grip keeps precedence where the strip meets a grip band |
| **Window animation** | the render-only open/close fade: a mount fades + slides in over 12 frames, a close-button close fades out over 10 frames before its unmount runs. The animating window is parked out of ebitenui's window pass and composited through one offscreen with alpha/translate — input is live throughout the open fade, inert throughout the close fade; no rects, layout or simulation state move |
| **Settle** | an animation completing: an open window snaps to the normal paint path, a closing window runs its deferred unmount. A raise settles every animation (nothing may fade below a retopped window); a new open mount settles the close fades only (the other open fades below it keep running — the composite walks the stack in paint order); a drag-arming press settles that window's open fade, so a fade's park flips can never relayout a subtree a drag is translating |

## The stat language (icons + families)

| Term | Meaning |
|---|---|
| **Stat family** | the hue a stat row is tinted by, one per kind of number: **Offence** (crimson), **Defence** (shield blue), **Capacitor** (green), **Mobility** (teal), **Utility** (info blue), **Mining** (amber), **Economy** (good green), **Fitting** (structure silver) — six owned hues in `theme.Palette` (`StatOffence`…`StatExplosive`) and six reused chrome roles; identity rows (Class, Maker, Origin, Family, Faction, Hull, Kind, Category, Qty) carry no glyph and no tint |
| **Damage sub-system** | the damage types are their own four families behind the eight — **EM** violet, **Thermal** red, **Kinetic** yellow, **Explosive** orange — one glyph per type serving its damage row, its EHP row and its resist row |
| **Stat table** | the one census (`uikit/theme/stat.go`): label → glyph + family, plus the section-bar map. Every renderer (info page rows and section bars, tooltip rows, the fitting window's stat rows and hull limits, stat-mapped table headers, HUD bar glyphs) reads it, so a new stat lights up on every surface or fails `TestStatTaxonomyCoversCensus` |
| **Paired info line** | the ship and module pages' stat layout: a section's rows sit on explicit lines of one to three equal cells (single rows are full-width), so related figures share a line and long or dynamic rows span it |
